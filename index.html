Enschedule

Helm chart repository

Deploy the Enschedule dashboard, workers, PostgreSQL, migrations, and log storage to Kubernetes from the public chart repository.

Install with Helm 3 0.1.0-alpha 
helm repo add enschedule https://ricsam.github.io/enschedule
helm repo update enschedule
helm upgrade --install enschedule enschedule/enschedule \
  --namespace enschedule \
  --create-namespace
Read the deployment guide View repository index Chart source
The chart is currently alpha. Pin chart and image versions, configure secrets, persistence, ingress, and backups before production use.
